# Just Wear This for Claude

This is the Just Wear This plugin store. Add it in Claude under Customize → Plugins → Add marketplace
(`ps-tools-store/dhxp-9pkw`), then install **Just Wear This** (and **Just Wear This Client Emails** if it's part of your purchase). In Claude Code:
`/plugin install just-wear-this --marketplace ps-tools-store/dhxp-9pkw` (add-on: `just-wear-this-emails`). Updates arrive through Check for updates (or turn on Sync automatically).
