# Just Wear This Client Emails (v1.0.0)

The outfit emails you'd write anyway, already written and sounding like you.

Five client emails, each with a short text version:

1. Six quick questions (sending the questionnaire)
2. Your outfit plan is ready
3. One week to go
4. Still looking for anything?
5. Thank you (and a peek)

The first time, Claude asks for two or three emails you've sent clients and learns your voice. After that, ask for
any email ("the one-week email for the Callahans") and it comes back filled in, ready to copy and send. With
Just Wear This installed, Claude offers the plan-ready email right after each outfit plan.

Nothing is ever sent for you. Copy and paste into your inbox, CRM or phone.

## Install

In the Claude app: Customize → Plugins → Add marketplace → `ebroadbent712/JWT`, then install
**Just Wear This Client Emails**.

In Claude Code:

    /plugin install just-wear-this-emails --marketplace ebroadbent712/JWT

Help: https://justwearthis.co
